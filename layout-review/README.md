# Floor plan review (EG / OG / DG)

`index.html` is the full review: rule check of the current plans, a hotel-design benchmark,
loop 1 (top floor only, two walls moved) and loop 2 (all three floors reworked), with plans
drawn to scale next to the original screenshots.

`plans.py` draws the proposal plans; `svg/` holds the four generated drawings on their own
(they rely on the CSS classes defined in `index.html`).
